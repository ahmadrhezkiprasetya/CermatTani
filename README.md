# CermatTani — Website (Next.js App Router + PWA)

Aplikasi web (PWA mobile-first) **CermatTani** dibangun menggunakan **Next.js 15 (App Router + TypeScript)** sesuai `PRD (1).md` dan `DESIGN (3).md` — khusus budidaya **tomat** berbasis computer vision + IoT surya + maskot **Cermo**.

## Cara Menjalankan

```bash
# 1. Pasang dependensi (jika belum)
npm install

# 2. Jalankan server pengembangan
npm run dev
```

Buka peramban di **http://localhost:3000**.

Untuk build produksi:
```bash
npm run build
npm run start
```
